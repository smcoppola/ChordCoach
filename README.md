# ChordCoach Companion

ChordCoach Companion is an AI-driven, cross-platform desktop application designed to accelerate piano proficiency using the Gemini Multimodal Live API.

## Installation

### Windows
Run the `ChordCoachCompanion_Setup.exe` from the latest release.

### macOS
For instructions on bypassing Gatekeeper for unsigned builds and locating logs, see:
